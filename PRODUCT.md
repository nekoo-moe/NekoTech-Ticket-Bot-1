# Product

## Register

product

## Users

Discord server owners, admins, and support staff who manage ticket systems. Owners set up the bot once (onboarding); staff use the dashboard daily to handle tickets, view stats, and manage the queue. Sold on marketplaces, so first impressions matter: the product must look and feel premium out of the box.

## Product Purpose

Heiznerd Tickets is a Discord ticket management bot with a web dashboard. The dashboard lets admins configure every aspect of the bot (categories, working hours, claiming, alerts, transcripts, reviews, suggestions, channel stats, archive) and lets staff manage open tickets, view closed history, read transcripts, and monitor performance. The onboarding wizard guides a new server owner through full configuration in one session, with live Discord embed previews so they see exactly what members will experience.

## Brand Personality

Precise, capable, unhurried. The tool that serious server operators reach for.

Three words: **sharp, legible, purposeful**.

## Anti-references

- Discord's own UI (blurple, rounded-everything, playful) — this is a professional ops tool, not a chat app
- Generic SaaS dashboards (light mode, blue primary, white cards, hero metrics) — too corporate, no identity
- Gamer aesthetic (neon green on black, aggressive gradients, RGB everything) — alienates non-gaming communities
- Notion/Linear clones (ultra-minimal, no color, monochrome) — too cold for a product sold on personality

## Design Principles

1. **Configuration is the product.** Every setting screen is a first-class surface, not an afterthought. Forms must be as considered as dashboards.
2. **Preview before commit.** Any change that affects what Discord members see (embed messages, panel buttons, category names) shows a live Discord-style preview before saving.
3. **Progressive disclosure.** Onboarding surfaces only what's needed to get started. Advanced settings are reachable but not in the way.
4. **Contrast earns trust.** Text is always readable. Muted text still passes 4.5:1. The palette never sacrifices legibility for mood.
5. **Staff efficiency first.** The daily-use surfaces (open tickets, ticket detail, queue) are optimized for speed: keyboard-friendly, dense but not cramped, no unnecessary clicks.

## Accessibility & Inclusion

WCAG AA minimum. All interactive elements keyboard-accessible. Color is never the sole indicator of state (always paired with icon or label). Reduced motion respected via `prefers-reduced-motion`.
